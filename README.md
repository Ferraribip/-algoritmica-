## Descripción General del Proyecto

Este repositorio (`/algoritmica/`) contiene el desarrollo lógico, diseño algorítmico mediante diagramas de flujo universales, pruebas de escritorio (simulación de memoria RAM en papel) y su traducción a código fuente funcional en **C++** para los cuatro ejercicios fundamentales de la Actividad 9. 

El objetivo principal es desacoplar el razonamiento lógico del lenguaje de programación y dominar el trazado de memoria paso a paso antes de escribir código en un entorno de desarrollo.
